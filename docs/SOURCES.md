# Official downloads and licensing

This repository contains original configuration and deployment scripts. Obtain application binaries, Yazi extensions and Nerd Font directly from their respective publishers. Do not commit bundled font or third-party installer files to this public repository.

- PowerShell: https://github.com/PowerShell/PowerShell/releases
- Windows Terminal: https://github.com/microsoft/terminal/releases
- Oh My Posh: https://ohmyposh.dev/docs/installation/windows
- Powerlevel10k Rainbow theme: https://github.com/JanDeDobbeleer/oh-my-posh/blob/main/themes/powerlevel10k_rainbow.omp.json
- Yazi: https://yazi-rs.github.io/docs/installation/
- Yazi plugins: https://github.com/yazi-rs/plugins
- Lazygit: https://github.com/jesseduffield/lazygit/releases
- fzf: https://github.com/junegunn/fzf/releases
- zoxide: https://github.com/ajeetdsouza/zoxide/releases
- bat: https://github.com/sharkdp/bat/releases
- ripgrep: https://github.com/BurntSushi/ripgrep/releases
- fd: https://github.com/sharkdp/fd/releases
- Git for Windows: https://gitforwindows.org/
- PSFzf: https://www.powershellgallery.com/packages/PSFzf
- Terminal-Icons: https://www.powershellgallery.com/packages/Terminal-Icons
- Nerd Fonts: https://github.com/ryanoasis/nerd-fonts/releases
- WinGet download: https://learn.microsoft.com/en-us/windows/package-manager/winget/download

A locally generated SHA-256 cache manifest detects file changes during copying but does not establish the authenticity or licensing of third-party downloads. Verify publisher signatures or checksums where available.
